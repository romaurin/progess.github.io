Политика конфиденциальности

Электронный журнал Progress хранит учебные данные (оценки, посещаемость, работы, обращения) на сервере колледжа. Данные доступны только вам, преподавателям и администрации в рамках их полномочий.

Для входа используется защищённая сессия в файле cookie (HttpOnly, 8 часов). Пароль хранится на сервере в виде хэша scrypt, пароль студента дополнительно шифруется для куратора.

Face ID, Touch ID и Windows Hello выполняются на вашем устройстве. Сервер получает только открытый ключ и подтверждение входа, биометрические данные не передаются и не хранятся.

Запросы на восстановление доступа и обращения видны администратору. Чтобы удалить данные, обратитесь к администратору колледжа.
